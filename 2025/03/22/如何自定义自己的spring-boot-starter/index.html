如何自定义自己的spring-boot-starter

本文最后更新于：2025年3月22日 下午

SpringBoot中如何实现starter的？

要想知道如何实现starter，就需要了解到Spring Boot中的自动装配原理

Spring Boot 自动装配

1. 基本概念

Spring Boot 的自动装配（Auto-Configuration）通过约定大于配置的原则，自动为应用程序配置所需的组件（如数据源、Web 容器等），减少开发者手动配置的工作量。

2. 核心机制

条件化装配
  • 条件注解：根据类路径、环境变量等条件决定是否装配 Bean。
    • @ConditionalOnClass：类路径存在某个类时生效。
    • @ConditionalOnMissingBean：容器中不存在指定 Bean 时生效。
    • @ConditionalOnProperty：根据配置文件属性生效。
自动配置类注册
  • META-INF/spring.factories：在 Starter 模块中声明自动配置类。
    org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
com.example.MyAutoConfiguration
触发入口
  • @EnableAutoConfiguration：启用自动装配，通常由 @SpringBootApplication 组合注解引入。

3. 工作流程

  1. 启动应用：通过 main 方法启动，加载 @SpringBootApplication。
  2. 扫描依赖：检查所有依赖中的 spring.factories 文件。
  3. 条件评估：根据条件注解过滤出有效的自动配置类。
  4. 注册 Bean：将符合条件的 Bean 注册到 Spring 容器。

自定义starter

工程目录

  1. 工程layree-psringboot-starter-autoconfigure中的pom.xml

    <dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-autoconfigure</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-configuration-processor</artifactId>
    </dependency>
</dependencies>

  2. 工程layree-springboot-starter中的pom.xml

    <dependencies>
       <dependency>
           <groupId>com.layree.autoconfigure</groupId>
           <artifactId>layree-spring-boot-starter-autoconfigure</artifactId>
           <version>1.0-SNAPSHOT</version>
       </dependency>
   </dependencies>

  3. 配置我们的自动装配配置类

    工程目录

    LayreeConfigProperties:配置我们自己的配置文件在yml中进行属性赋值

    @ConfigurationProperties(prefix = "layree")
public class LayreeConfigProperties {

    private String name;

    private String age;

    public void setName(String name){
        this.name = name;
    }

    public String getName(){
        return name;
    }

    public String getAge() {
        return age;
    }

    public void setAge(String age) {
        this.age = age;
    }
}

    LayreeServiceTemplate:我们自定义的Bean,将配置文件类注入，自定义方法

    public class LayreeServiceTemplate {

    private LayreeConfigProperties layreeConfigProperties;

    public LayreeConfigProperties getLayreeConfigProperties() {
        return layreeConfigProperties;
    }

    public void setLayreeConfigProperties(LayreeConfigProperties layreeConfigProperties) {
        this.layreeConfigProperties = layreeConfigProperties;
    }

    public String say(String msg){
        return layreeConfigProperties.getName() + "今年" + layreeConfigProperties.getAge()+ "说:" + msg;
    }

}

    LayreeAutoConfiguration:配置我们的配置类，SpringBoot启动时扫描配置，自动注入

    @Configuration
@ConditionalOnClass(LayreeServiceTemplate.class)
@EnableConfigurationProperties(LayreeConfigProperties.class)
public class LayreeAutoConfiguration {

    @Autowired
    private LayreeConfigProperties layreeConfigProperties;

    @Bean
    @ConditionalOnMissingBean
    public LayreeServiceTemplate layreeServiceTemplate(){
        LayreeServiceTemplate template = new LayreeServiceTemplate();
        template.setLayreeConfigProperties(layreeConfigProperties);
        return template;
    }


}

    META-INF/spring.factories配置我们自动配置的配置类位置，SpringBoot自动扫描加入容器中

    # Auto Configure
  org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
  com.layree.starter.config.LayreeAutoConfiguration

  4. 配置layree-springboot-starter,基本上不用动，只需要依赖引入layree-psringboot-starter-autoconfigure,同2
